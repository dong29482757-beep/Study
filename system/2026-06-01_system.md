## [OS / 운영방식] 분산 처리 시스템

### 📌 핵심 원리

- **지리적으로 분산된** 여러 컴퓨터를 통신망으로 연결
- 하나의 대형 컴퓨터처럼 **작업을 분담**하여 처리
- 중앙 집중형과 반대 개념 → 자원 공유, 신뢰성·유연성 향상

### 🏃 손 디버깅 흐름

| 처리 방식 | 핵심 키워드 | 특징 |
|-----------|------------|------|
| **일괄 처리** (Batch) | "모아서 한꺼번에" | 응답 느림, 초기 OS |
| **다중 프로그래밍** | "하나의 CPU, 여러 프로그램" | CPU 유휴시간 최소화 |
| **시분할** (Time Sharing) | "Time Slice" | 대화형, 응답성 우수 |
| **실시간** (Real-Time) | "정해진 시간 내 반드시" | 경성(Hard) / 연성(Soft) |
| **분산 처리** | "지리적 분산 + 통신망 + 하나처럼" | 자원 공유, 신뢰성 향상 |

> 💡 다중 프로그래밍 vs 시분할 — 둘 다 여러 프로그램, 차이는 **시간을 쪼개냐 아니냐**

### ⭕ 정답

```
분산 처리 시스템 (Distributed Processing System)
```

## [네트워크 / 프로토콜] IGMP

### 📌 핵심 원리

- **IP 멀티캐스트 그룹**의 멤버십을 구성·관리하는 프로토콜
- 호스트 ↔ 라우터 사이에서 그룹 **가입/탈퇴** 메시지 교환
- 멀티캐스트 트래픽을 효율적으로 제어하기 위한 필수 프로토콜

### 🏃 손 디버깅 흐름

| 전송 방식 | 대상 | 설명 |
|-----------|------|------|
| **유니캐스트** (Unicast) | 1 : 1 | 특정 단일 호스트에게만 전송 |
| **브로드캐스트** (Broadcast) | 1 : All | 망 내 모든 호스트에게 전송 |
| **멀티캐스트** (Multicast) | 1 : Group | 특정 그룹 가입 호스트에게만 전송 → **IGMP가 멤버십 관리** |

> 💡 **IGMP 스누핑**: 스위치가 IGMP 메시지를 분석해 필요한 포트에만 멀티캐스트 포워딩

### ⭕ 정답

```
IGMP (Internet Group Management Protocol)
```

## 📎 보충 개념 — 네트워크 프로토콜 계층별 정리

### 📌 핵심 원리

- OSI 7계층 중 시험에 자주 나오는 **3계층 / 4계층 / 7계층** 프로토콜 집중 암기
- 계층별 역할과 프로토콜 이름(약어 + 풀네임) 세트로 외우기

### 🏃 손 디버깅 흐름

**3계층 — 네트워크 계층 (라우터 · IP 주소 기반 경로 탐색)**

| 약어 | 풀네임 | 역할 |
|------|--------|------|
| **IP** | Internet Protocol | 패킷을 목적지까지 전달하는 기본 주소 체계 |
| **ICMP** | Internet Control Message Protocol | 네트워크 오류 보고·제어 (Ping의 기반) |
| **IGMP** | Internet Group Management Protocol | 멀티캐스트 그룹 멤버십 관리 (가입/유지/탈퇴) |
| **ARP** | Address Resolution Protocol | IP 주소 → MAC 주소 변환 |
| **RARP** | Reverse Address Resolution Protocol | MAC 주소 → IP 주소 변환 (ARP 반대) |
| **RIP** | Routing Information Protocol | 거리 벡터 기반 라우팅 프로토콜 |
| **OSPF** | Open Shortest Path First | 링크 상태 기반 라우팅 프로토콜 (대규모 네트워크) |

> 💡 **I로 시작하는 IP, ICMP, IGMP → 전부 3계층!**

---

**4계층 — 전송 계층 (포트 번호 기반, 프로그램까지 배달)**

| 약어 | 풀네임 | 역할 |
|------|--------|------|
| **TCP** | Transmission Control Protocol | 연결 지향, 신뢰성 보장, 데이터 분실 시 재전송 |
| **UDP** | User Datagram Protocol | 비연결형, 신뢰성보다 속도 우선 (스트리밍, 게임) |

> 💡 **TCP = 느리지만 정확 / UDP = 빠르지만 불안정**

---

**7계층 — 응용 계층 (사용자가 직접 사용하는 서비스)**

| 약어 | 풀네임 | 역할 |
|------|--------|------|
| **HTTP** | HyperText Transfer Protocol | 웹 페이지 전송 |
| **FTP** | File Transfer Protocol | 파일 전송 |
| **SMTP** | Simple Mail Transfer Protocol | 이메일 발신 |
| **DNS** | Domain Name System | 도메인 이름 → IP 주소 변환 |

> 💡 **DNS = 인터넷 전화번호부** / **SMTP = 보내는 메일, POP3·IMAP = 받는 메일**
